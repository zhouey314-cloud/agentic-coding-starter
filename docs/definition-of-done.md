# Definition of Done

A change is done when its acceptance criteria pass and its status is stated precisely. Compilation or an HTTP 200 does not establish AI answer quality. A local demo does not establish provider or platform behavior. Test deterministic mechanics; evaluate probabilistic behavior with reviewed cases and a release gate. Scan both current files and reachable Git history for secrets. Record integration state as `NOT_CONFIGURED` when credentials are absent. A handoff must identify how to run, what was verified, what failed, what is deferred and how to roll back.
